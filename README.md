# People’s Place Church website

A responsive, static website for People’s Place Church. The design uses the public content and prayer photograph from the existing Google Site.

## Files

- `index.html`: the website, with embedded styles and script. No build or installation is required.
- `assets/prayer.jpg`: the prayer photograph from the original Google Site.
- `.nojekyll`: tells GitHub Pages to serve the files directly.

## Publishing

In repository **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/ (root)**. GitHub Pages will publish changes to `index.html` automatically after a commit.

## Editing

Edit the HTML to update text, links, colors, or gathering information. The page includes an accessible mobile menu, expandable beliefs, and reduced-motion support. You can open `index.html` directly in a browser to preview it.

Current destinations are the existing General Giving Givebutter campaign, the existing Google Forms signup, and the church contact email. The site does not itself collect or store donations or personal information.

## Content source

- https://sites.google.com/colepax.com/peoples-place-church/home
- https://sites.google.com/colepax.com/peoples-place-church/who-we-are

The full vision and seven belief descriptions follow the source site. Scripture references link to the ESV on Bible Gateway. No service time or location has been invented; visitors can request gathering details by email.

## Checks

Desktop rendering, internal link targets, and image loading were checked. The page includes responsive layout rules, keyboard navigation, and native expandable content.
